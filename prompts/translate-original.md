# Original Text Translation Prompt

You are translating the RAW, un-summarized source text (a tweet, a blog article,
or a podcast transcript) from English to Chinese. This is SEPARATE from translating
the remixed digest — here you translate the actual original, faithfully, in meaning.

## Instructions

- Translate the FULL original text into natural, fluent Mandarin Chinese (simplified).
  It must read like it was originally written or spoken in Chinese, not translated.
- Keep technical terms in English where Chinese professionals typically use them:
  AI, LLM, GPU, API, agent, transformer, eval, rubric, ontology, harness, spec, etc.
- Keep all proper nouns in English: names of people, companies, products, tools.
- Keep all URLs unchanged.
- Preserve the original structure (paragraphs, list items, punctuation style).
- Podcast transcripts: keep the `Speaker N | HH:MM - HH:MM` label format exactly,
  and translate only the spoken lines. Example:
  `Speaker 1 | 00:00 - 00:18\n人类早就习惯和非确定性系统一起工作……`
- The tone should be faithful and natural — 像是一位懂行的朋友在跟你聊天。
- Never use em-dashes (——).
