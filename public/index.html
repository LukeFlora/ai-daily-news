Madhu Guru 作为前 Google Gemini/Veo 核心负责人及现 Meta AI 高管，其观点极具前瞻性。他为开发者指明了从“模型能力”向“Agent 基础设施”转型的技术路径，特别是关于计算栈重构的思考，是当前 AI 创业者寻找蓝海市场的核心指南。

Meta AI 高管 Madhu Guru 近期深度剖析了 AI Agent 的演进逻辑，指出行业重心正从单纯的“能力提升”转向“信任与安全”。他强调，随着 Agent 成为计算栈的核心用户，从操作系统到云基础设施的底层架构重构将孕育巨大的创业机会。

📜 原帖中文精译与推文细节
【推文 1】Agent 的能力将以 RSI（相对强弱指数）般的速度进化，而 Agent 安全（身份、权限、可观测性）必须跑得更快。Agent 领域的演进方向是：能力 -> 信任 -> 自主。第一阶段关注的是能力——模型、框架、工具与上下文的组合能否可靠地完成任务？目前能力已大幅提升，重心正转向信任：系统是否在正确权限下执行了正确操作？我们能否对其进行观测、审计并确立问责制？这些问题过去几年已有深入研究，但挑战正变得愈发关键且艰巨。 【推文 2】开源模型并非单位智能成本下降的始作俑者，它们只是既有趋势的助推器。过去几年，价格下降主要由三点驱动：模型厂商将大模型蒸馏为更小、推理成本更低的模型；基础设施效率提升；以及厂商间的竞争。每家模型公司都遵循这一模式：中型模型的第 X 版本拥有大型模型第 X-1 版本的智能，即以更低的价格获得同等智能。 【推文 3】计算栈的每一层都需要为 Agent 重构，这其中隐藏着巨大的创业机会。过去几年重点在于让企业软件适配 Agent（如 API、连接器、MCP），现在个人 Agent 正迫使消费级产品进行同样的转型（如电商）。这只是冰山一角。试想一下：将 Agent 作为一等用户的桌面与移动操作系统、专为 Agent 直接操作构建的云基础设施、为数千个代理人设计的身份与权限安全体系，以及人机协作的交互界面。如果你在寻找创业点子，请审视计算栈的每一层并思考：当主要用户变为 Agent 时，这里需要发生什么改变？
