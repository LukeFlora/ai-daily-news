Box CEO Aaron Levie 指出，当前企业级 AI Agent 的实际渗透率仍不足 1%，多数应用仅停留在简单的单次 LLM 调用阶段

✦ 洞察

Aaron Levie 从资深企服大佬的视角点出了 AI Agent 落地痛点与突破口：AI 自动化正从个人任务级的单次 Prompt，走向企业系统级的“工作流重构”。推荐开发者和创业者关注 Computer Use、长程任务处理与智能体集群（Swarms）等方向，在信息密集型行业寻找深度集成的商业机会。

Box CEO Aaron Levie 指出，当前企业级 AI Agent 的实际渗透率仍不足 1%，多数应用仅停留在简单的单次 LLM 调用阶段。然而，随着 Computer Use（计算机操作能力）、长程 Agent 和智能体集群（Agent Swarms）等技术的成熟，AI 正在从“终端用户交互的 Prompt 工具”演变为“重构企业底层工作流”的技术引擎，在金融、医疗等信息密集型领域蕴含巨大落地机会。

📜 原帖中文精译与推文细节
确实如此。绝大多数企业工作流实际上尚未以任何有意义的方式应用 Agent。从整个经济体来看，目前的应用渗透率可能还不足 1%。 企业充其量只有几个自动化系统通过单次 LLM 调用来进行决策或提供反馈，但几乎没有实现真正意义上的“自动化”。这在一定程度上反映了企业对新技术的采纳速度，但绝大部分原因其实归咎于 AI 能力本身。 这一切正在发生改变。如今，随着 Computer Use（计算机操作能力）、长程 Agent、框架改进以及周边基础设施的发展，我们终于到了可以将 Agent 应用于更复杂工作流的节点。 我们将看到具备自我改进能力的系统，它们可以针对特定的工作流目标，在大量运行实例中不断提升执行成功率。而随着 Agent Swarms（智能体蜂群/集群）这一新形态的出现，你只需为某个问题投入任意规模的算力，Agent 就会自动去执行并完成工作。 这不再是终端用户通过 Prompt 驱动 Agent 完成某项具体任务，而是企业从底层重构其业务工作流，将 Agent 深度融入流程之中。这将对金融、生命科学、医疗和其他信息密集型领域产生深远影响。当下正是构建和部署这些系统的巨大机遇期。
