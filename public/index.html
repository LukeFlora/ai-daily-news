How we contain Claude across products

Anthropic Engineering · 官方技术博客

【推荐理由】该文为构建 Agent 系统提供了极具价值的工程范式：从依赖人工监督转向基于沙箱和网络出口控制的架构隔离。对于正在开发 Agent 产品并面临安全合规挑战的团队，文中关于“批准疲劳”的实证分析及分层防御策略具有直接的参考意义。

Anthropic 在本文中探讨了如何通过“限制爆炸半径（Blast Radius）”来安全部署 Claude 智能体。核心观点在于，随着模型能力增强，单纯依赖“人在回路（Human-in-the-loop）”的监督机制因用户疲劳（93%的批准率）而失效，因此必须转向环境隔离（Containment）。Anthropic 通过沙箱、虚拟机和出口控制等技术手段，针对 claude.ai、Claude Code 和 Claude Cowork 三类产品构建了差异化的安全架构，旨在平衡模型的高效能与系统安全性。

十二个月前，我们绝不会允许 Claude 拥有足以破坏内部服务的权限，但现在这已成为常态。部署智能体的风险由“故障概率”和“潜在损害”组成。随着模型能力提升，我们必须通过控制环境来限制其“爆炸半径”。我们发现，依赖用户手动批准的监督模式存在严重的“批准疲劳”，因此转向了更可靠的容器化和访问边界控制。本文分享了我们在 claude.ai、Claude Code 和 Claude Cowork 三款产品中，针对不同场景实施安全隔离的架构经验与教训。

Scaling Managed Agents: Decoupling the brain from the hands

Anthropic Engineering · 官方技术博客

【推荐理由】该架构为构建企业级 Agent 系统提供了极佳的解耦范式，特别适合需要长期运行、高可靠性要求的复杂业务场景。建议研发团队参考其“接口抽象化”设计，避免将业务逻辑与执行环境深度绑定，以应对模型能力升级带来的架构过时风险。

Anthropic 发布了“托管智能体（Managed Agents）”服务，旨在解决长周期智能体任务中的架构耦合问题。核心设计理念借鉴了操作系统对硬件的虚拟化思路，将智能体拆解为 Session（会话日志）、Harness（执行逻辑）和 Sandbox（运行环境）三个独立接口。通过这种解耦，Anthropic 避免了将智能体视为“宠物（Pet）”式的单体维护模式，实现了基础设施与模型逻辑的隔离，使系统能够适应模型能力的快速迭代，并支持更稳定、可扩展的长任务执行。

Anthropic 推出 Managed Agents，旨在通过标准化接口将智能体的“大脑”（模型逻辑）与“双手”（执行环境）解耦。正如操作系统通过抽象化硬件（如文件系统）来支持未知的应用程序，Managed Agents 将智能体拆分为会话、执行器和沙箱。这种架构不仅解决了模型因上下文焦虑导致的提前终止问题，还通过消除单体容器的依赖，将智能体从难以维护的“宠物”转变为可替换的“牲畜”，从而确保基础设施的稳定性与长效性。

FPV Ventures 合伙人 Nikunj Kothari 领投了燃料支...

Nikunj Kothari · partner @fpvventures - investing in seed/A. previous: early hire @meter, @opendoor, @atlassian & others. love @shimoleejhaveri + 👦👧

【为何关注】该案例展示了如何通过“去中介化”重构传统行业支付流程，是典型的“深科技+垂直领域”创新。对于 AI 从业者而言，Piston 证明了深入理解业务痛点（如欺诈与对账）比单纯堆砌技术更能创造商业价值。

FPV Ventures 合伙人 Nikunj Kothari 领投了燃料支付平台 Piston 的 A 轮融资。Piston 通过绕过传统银行卡网络，建立闭环支付系统，从根本上解决了车队燃油欺诈问题，目前已覆盖全美 2000 个加油站。

我长期以来一直痴迷于闭环支付，并一直在寻找能够解决实际问题的公司……很高兴最终投资了 Piston (piston.com) ⛽️。 仅在美国，每年在燃油上的支出就高达数千亿美元。大部分支出通过信用卡（信用卡、燃油卡或内部卡）完成。然而，许多卡片甚至没有与特定驾驶员绑定，经常被盗、被侧录或滥用。车队所有者不得不承担欺诈损失，并花费大量时间进行对账。加油站为了接受这些卡片必须支付交换费，却与另一端的车队没有任何直接联系。许多公司试图优化这种基础设施，却未从源头思考问题。 你无法仅仅通过制造一张更好的燃油卡来解决这个问题。卡片本身就是问题所在，因此 Piston 决定彻底抛弃它。它通过自己的轨道进行支付，无需网络或任何中介。Piston 向加油站付款，然后向车队开具发票。每笔交易都绑定到特定的驾驶员，并附带时间、地点和燃油类型，很快它还将与车辆本身集成。 创始人亲身经历过这个问题。@vik_sekhon 经营着自己的卡车车队，他的车队因燃油欺诈损失了真金白银。@Shivam2291 曾招聘过数千名司机，随后两人联手打造了 Piston。衡量 Piston 对车队有效性的最佳信号是：当他们切换到 Piston 时，燃油支出会自动下降。我见过许多直接证明这一点的图表和客户评价。 客户的喜爱体现在指标上。支付额增长了 8 倍，商户网络增长了 40 倍，而留存率保持在 98% 以上。Piston 目前已在全美 48 个州的 2000 个加油站上线。车队目前无需支付任何费用，即可获得卡片系统无法提供的欺诈预防功能。加油站则获得了与车队直接联系的渠道，有助于建立忠诚度并提供周边产品。 为了扩大覆盖范围，Piston 现在已与美国大多数加油站的 POS 系统直接集成。这使他们能够一次性接入数百个加油站，确保供应，从而满足其日益增长的需求。 很高兴能领投他们的 A 轮融资并加入董事会，与现有投资者 @sparkcapital 和 @pearvc 并肩作战。特别感谢 @arpans 去年将我介绍给这个团队！ [推文 2] 给 Dreamforce 新访客的公告：在市内通勤时，Lyft 自行车比花几个小时堵在 Waymo/Uber 里要快得多。SOMA 区的专用自行车道让骑行变得轻而易举。就像开源模型一样，你用 10% 的时间就能获得 90% 的价值！
