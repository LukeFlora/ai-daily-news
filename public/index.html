隆重介绍 gdp-ts：TypeScript 的“已逝证明之魂（Ghosts of Departed Proofs）”。 gdp-ts 是一个用于更安全 API 设计的库、Linter 和 AI 技能。根据此契约，敏感函数要求调用者提供已执行授权检查的“证明”。 类型检查器会在编译时验证这些证明，防止你的团队和 AI Agent 发布灾难性的安全漏洞（以及其他类型的 Bug）。 虽然这些模式在 Haskell 等生态系统中早已存在，但由于 ① 人工代码审查的局限性，以及 ② 认知和语法开销过大，这些方案一直处于小众地位。 现在情况反转了。AI Agent 编写代码的速度已远超人类审查能力，且它们在人类会感到沮丧的严苛约束循环中表现得游刃有余。Rust、借用检查器（Borrow Checker）以及代码美学争论的兴起，都印证了这一点。 README 和示例模拟了 Vercel 真实世界的 API 产品约束：修改项目密码需要提供特定角色 + 特定权限的证明。感谢 Matt Noonan 和 Ollie Charles 在该领域的研究。
