Anthropic 在本文中探讨了如何通过“限制爆炸半径”（Blast Radius）来安全部署 Claude 智能体。核心观点认为，随着模型能力增强，单纯依赖“人在回路”（Human-in-the-loop）的监督模式因用户疲劳（93%的批准率）而失效，必须转向“容器化防御”（Containment）。Anthropic 通过沙箱、虚拟机及出口流量控制等架构手段，针对 claude.ai、Claude Code 和 Claude Cowork 三类产品构建了差异化的安全边界，旨在平衡高能力智能体的生产力提升与系统安全性风险。

一年前，我们绝不会允许 Claude 拥有可能导致内部服务瘫痪的权限，但现在这已成为常态。部署风险由“失败概率”和“潜在损害”组成，随着模型能力提升，我们必须通过控制环境来限制其“爆炸半径”。我们发现，依赖用户手动批准的监督模式存在严重的“批准疲劳”，因此转向了更底层的容器化防御，通过沙箱、虚拟机和出口控制来限制智能体的操作权限。针对不同的产品形态，我们构建了多层次的防御架构，以应对用户误用、模型越狱及智能体自主行为带来的安全挑战。

Anthropic 近期针对 Claude Code 用户反馈的性能下降问题进行了深度复盘。调查发现，问题源于三个独立的技术变更：一是将默认推理强度从“高”降为“中”导致模型智力下降；二是会话清理逻辑的 Bug 导致模型出现重复性遗忘；三是过度的系统提示词优化反而损害了代码质量。目前所有问题已在 v2.1.116 版本修复。Anthropic 强调，此类问题并非模型本身退化，而是产品层面的配置与逻辑错误，公司已通过重置订阅用户限额等措施进行补偿，并承诺改进评估体系以更早识别此类偏差。

过去一个月，我们调查了关于 Claude 响应质量下降的反馈。经排查，API 层未受影响，问题集中在 Claude Code、SDK 及 Cowork 产品层。我们识别出三个主要原因：3月4日将默认推理强度调低以优化延迟，导致智力下降；3月26日的会话清理逻辑存在 Bug，导致模型表现出重复和遗忘；4月16日的冗余抑制提示词意外损害了代码质量。所有问题已于4月20日修复。我们从未故意降低模型性能，未来将优化评估流程，确保此类产品层面的配置错误不再发生。

【推荐理由】该架构为构建企业级 AI Agent 提供了极佳的工程范式：通过接口抽象实现组件解耦，避免业务逻辑与模型特定行为深度绑定。对于需要处理长周期复杂任务的研发团队，这种“基础设施即抽象”的设计能显著降低模型升级带来的重构成本。

Anthropic 发布了“托管智能体（Managed Agents）”服务，旨在解决长期运行智能体在架构上的耦合难题。核心设计理念借鉴了操作系统对硬件的虚拟化思想，通过将智能体的会话（Session）、控制逻辑（Harness）和执行环境（Sandbox）解耦，实现了组件的独立替换与升级。该架构避免了将智能体视为“宠物（Pet）”式的单体维护模式，转向“牛群（Cattle）”式的可扩展服务，从而有效应对模型能力迭代带来的架构过时问题，确保系统能适应未来更先进的 AI 模型。

Anthropic 推出 Claude 托管智能体，通过将智能体的“大脑”（模型逻辑）与“双手”（执行环境）解耦，构建了更具韧性的系统。文章指出，传统的智能体架构往往过度依赖模型特定行为（如针对上下文限制的补丁），随着模型能力提升，这些补丁常沦为冗余。借鉴操作系统抽象硬件的思路，Anthropic 将智能体拆分为会话、控制逻辑和沙箱，通过标准接口实现各部分的独立演进，彻底解决了单体容器化部署带来的维护痛点。

FPV Ventures 合伙人 Nikunj Kothari 领投了燃料支付平台 Piston 的 A 轮融资。Piston 通过绕过传统信用卡网络，利用自有支付轨道解决车队燃油欺诈问题，实现了支付量 8 倍增长及 98% 以上的客户留存率。

我长期以来一直痴迷于闭环支付，并一直在寻找一家试图解决实际问题的公司……很高兴最终投资了 Piston (piston.com) ⛽️。 仅美国在燃油上的支出就高达数千亿美元。大部分支出通过卡片（信用卡、燃油卡或内部卡）完成。然而，许多卡片甚至没有绑定特定司机，经常被盗、被侧录或滥用。车队所有者不得不承担欺诈损失，并花费大量时间核对账目。加油站为了接受这些卡片必须支付手续费，却与另一端的车队没有任何直接联系。许多公司试图优化这种基础设施，却没能从源头思考问题。 你无法仅通过制造一张更好的燃油卡来解决这个问题。卡片本身就是问题所在，因此 Piston 决定彻底抛弃它。它将支付转移到自己的轨道上，无需网络或任何中介。Piston 向加油站付款，然后向车队开具发票。每笔交易都绑定了特定的司机、时间、地点和燃油类型，很快它还将与车辆本身集成。 创始人亲身经历过这个问题。@vik_sekhon 经营着自己的卡车车队，他的车队因燃油欺诈损失了真金白银。@Shivam2291 曾招聘过数千名司机，两人联手打造了 Piston。衡量 Piston 对车队有效性的最佳信号是：当他们切换到 Piston 时，燃油支出会自动下降。我见过许多图表和客户评价直接证明了这一点。 客户的喜爱体现在数据上。支付量增长了 8 倍，商户网络增长了 40 倍，而留存率保持在 98% 以上。Piston 目前已覆盖全美 48 个州的 2,000 个加油站。车队目前无需支付任何费用，即可获得卡片系统无法提供的防欺诈功能。加油站则获得了与车队直接联系的渠道，有助于建立忠诚度并提供周边产品。 为了扩大覆盖范围，Piston 现在直接与美国大多数加油站的 POS 系统集成。这使他们能够一次性激活数百个加油站，确保供应，从而满足他们日益增长的需求。 很高兴能领投他们的 A 轮融资并加入董事会，与现有投资者 @sparkcapital 和 @pearvc 并肩作战。特别感谢 @arpans 去年将我介绍给这个团队！
