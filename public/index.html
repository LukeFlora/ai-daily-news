Box CEO Aaron Levie 指出，编程领域是知识工作未来的缩影

✦ 洞察

Levie 深刻揭示了 AI Agent 对知识工作范式的重构逻辑，即“一切皆代码”。对于 AI 从业者而言，这不仅是技术趋势的预判，更是思考如何构建下一代工作流（Workflow）的核心参考。

Box CEO Aaron Levie 指出，编程领域是知识工作未来的缩影。随着 AI Agent 从“辅助执行”进化为“目标导向的自主解决问题”，各行各业的知识工作都将向编程范式靠拢，最终实现生产力的跨越式增长。

📜 原帖中文精译与推文细节
编程为你提供了一个窗口，让你窥见未来大量知识工作的样貌。 大多数工作的演进第一步，是从手动完成研究、打字和价值创造（即便是在使用数字工具），转变为协调 AI Agent 的工作。接下来，当这种协调工作本身变得冗余或拖慢 Agent 的效率时，我们将直接为 Agent 设定优化目标，让它们自主去解决更宏大的问题。 乍看之下，这似乎只会影响编程领域，但实际上，由于能带来巨大的生产力提升，绝大多数知识工作最终都将向这种范式收敛。Agent 将会操作计算机、利用现有工具或编写新工具，并实时编写代码来解决更广泛的知识工作任务。 因此，即使某些任务现在看起来与“编程”无关，它们最终也可能演变成“类编程”任务，涵盖制造业、建筑学、生命科学、材料科学、网络安全等领域。 最终的一个大障碍是，这些工作中有许多仍无法验证，因此人类在其中的参与度将比在纯编程领域更高。但随着模型能力的提升，人类能够移交的任务比例会越来越大。 简而言之，关注编程，你就能洞察未来工作的走向。
