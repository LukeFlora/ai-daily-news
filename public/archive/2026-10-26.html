I'd describe this particular OpenAI find as a 'noisy neighbor' attack. If two agents are on the same machine, one can make enough noise (through the CPU caches!) that the other one can detect it by timing its own computation and cache accesses. The only "complete" solution would be for each agent to run on its own dedicated hardware, which obviously has significant economic consequences.
