How we contain Claude across products

Anthropic Engineering · 官方技术博客

【推荐理由】该文为构建企业级 AI Agent 提供了极具参考价值的架构思路，特别是关于如何通过环境隔离（而非单纯依赖提示词或人工确认）来降低系统风险的工程实践，对 AI 产品研发团队具有直接的落地指导意义。

本文探讨了 Anthropic 如何通过“限制爆炸半径（Blast Radius）”策略，在提升 Claude 智能体自主性的同时确保系统安全。核心观点在于，随着模型能力增强，单纯依赖“人在回路（Human-in-the-loop）”的监督模式因用户疲劳（93%的批准率）而失效，必须转向环境隔离与访问控制。Anthropic 针对 claude.ai、Claude Code 和 Claude Cowork 三类产品，通过沙箱、虚拟机及出口流量控制等手段构建了多层防御体系，旨在平衡高生产力与潜在的安全风险。

一年前，我们绝不会允许 Claude 拥有可能导致内部服务瘫痪的权限，但现在这已成为常态。风险由“故障概率”和“潜在损害”两部分组成，随着模型能力提升，我们必须通过限制环境权限来控制“爆炸半径”。我们发现依赖人工确认的监督模式存在严重的“批准疲劳”，因此转向了更可靠的容器化与沙箱隔离技术。针对不同产品，我们构建了差异化的防御架构，以应对用户误用、模型越狱及恶意攻击等安全挑战。

Scaling Managed Agents: Decoupling the brain from the hands

Anthropic Engineering · 官方技术博客

【推荐理由】该架构为构建企业级 Agent 系统提供了极佳的范式，通过接口解耦避免了模型升级带来的重构成本。对于需要处理复杂、长周期任务的研发团队，借鉴其“组件虚拟化”设计可显著提升系统的鲁棒性与可维护性。

Anthropic 发布了“托管智能体（Managed Agents）”服务，旨在解决长周期智能体任务中的架构耦合问题。核心设计理念借鉴了操作系统对硬件的虚拟化思路，将智能体拆解为 Session（会话日志）、Harness（执行逻辑）和 Sandbox（运行环境）三个独立抽象层。通过这种解耦，Anthropic 避免了将智能体视为“宠物”式维护的困境，实现了组件的可插拔与可扩展性，确保底层模型迭代时，上层架构无需频繁重构。

Anthropic 推出 Managed Agents，通过将智能体的“大脑”（模型逻辑）与“双手”（执行环境）解耦，构建了长效运行的智能体服务。该架构将智能体虚拟化为会话、执行器和沙箱三个独立组件，类似于操作系统对硬件的抽象。这种设计解决了以往因模型能力提升导致旧版执行逻辑（如上下文焦虑处理）失效的问题，使系统能够适应未来模型的演进，从“宠物式”维护转向“牛群式”可扩展管理。

Claude Code now supports artifacts

Claude Blog · 官方技术博客

【推荐理由】该功能将 AI 编码从“黑盒对话”升级为“可视化协作”，极大提升了复杂工程任务（如故障排查、代码重构）的透明度。对于研发团队而言，它不仅是高效的文档工具，更是实现 AI 辅助决策与团队同步的标准化接口，具有极高的落地价值。

Claude Code 现已支持 Artifacts 功能，允许开发者将 AI 编码会话过程转化为实时、可共享的交互式网页。该功能利用会话上下文（代码库、监控数据、推理过程），自动生成 PR 导览、系统分析报告、仪表盘及发布清单等可视化页面。Artifacts 支持实时更新与版本回溯，团队成员可通过同一链接查看最新进展，无需手动同步状态。此外，该功能具备企业级安全保障，默认私有，支持细粒度的权限管理与合规审计，旨在通过可视化协作大幅降低沟通成本。

从今天起，Claude Code 能够将工作进度捕捉为 Artifacts，将 AI 的工作转化为实时、可共享的可视化页面，包括 PR 导览、系统解释器、仪表盘和发布清单等，并随会话进程自动更新。Artifacts 基于会话的完整上下文（代码、连接器、对话记录）构建，无需额外配置数据源或基础设施。页面支持实时刷新，团队成员可即时获取最新版本，并提供版本历史记录。所有 Artifacts 默认仅对组织内部可见，管理员可通过权限控制和合规 API 进行统一管理。

FPV Ventures 合伙人 Nikunj Kothari 领投了燃料支付平台 Piston 的 A 轮融资。Piston 通过绕过传统信用卡网络、建立闭环支付系统，有效解决了车队燃油欺诈问题，目前已覆盖全美 2000 个站点，展现出极高的客户留存率。

【推文 1】我长期以来一直痴迷于“闭环支付”领域，并一直在寻找能真正解决实际问题的公司……很高兴最终投资了 Piston (piston.com) ⛽️。 仅在美国，每年在燃油上的支出就高达数千亿美元。大部分支出通过信用卡（信用卡、燃油卡或内部卡）完成。然而，许多卡片甚至没有绑定特定司机，极易被盗、被侧录或滥用。车队所有者不得不承担欺诈损失，并花费大量时间进行对账。加油站既要支付高额的交换费，又无法与车队建立直接联系。此前许多公司试图优化现有基础设施，而非从底层逻辑重构。 仅靠制造一张更好的燃油卡无法解决问题。卡片本身就是症结所在，因此 Piston 决定彻底抛弃它。它在自有轨道上进行支付，无需网络或任何中介。Piston 直接向加油站付款，然后向车队开具发票。每笔交易都绑定了特定的司机、时间、地点和燃油类型，未来还将与车辆本身集成。 创始人亲身经历过这一痛点。@vik_sekhon 经营着自己的卡车车队，曾因燃油欺诈遭受真实损失；@Shivam2291 曾负责招聘数千名司机。他们联手打造了 Piston。最能证明 Piston 有效性的信号是：车队一旦切换到 Piston，燃油支出会自动下降。我看到的图表和客户评价直接印证了这一点。 客户喜爱度体现在数据上：支付额增长了 8 倍，商户网络增长了 40 倍，留存率保持在 98% 以上。Piston 现已覆盖全美 48 个州的 2000 个加油站。目前车队无需付费即可获得卡片系统无法提供的防欺诈功能，而加油站则获得了与车队直接对接以建立忠诚度并提供周边产品的机会。 为了扩大覆盖范围，Piston 现已直接集成到美国大多数加油站的 POS 系统中。这使他们能够一次性接入数百个加油站，确保供应，从而满足日益增长的需求。 很高兴能领投他们的 A 轮融资并加入董事会，与现有投资者 @sparkcapital 和 @pearvc 并肩作战。特别感谢 @arpans 去年将这个团队介绍给我！ 【推文 2】给 Dreamforce 新访客的公告：在市内通勤时，骑 Lyft 自行车比被困在 Waymo 或 Uber 里数小时要快得多。SOMA 区的专用自行车道让骑行变得轻而易举。就像开源模型一样，你用 10% 的时间就能获得 90% 的价值！
