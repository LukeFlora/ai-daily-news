Box CEO Aaron Levie 指出，AI Agent 不仅将重塑商业交易模式，还将成为软件交互的主力军。随着 Agent 处理任务复杂度的提升，能够提供安全防护、数据治理及业务逻辑编排的平台将迎来巨大的商业机遇。

📜 原帖中文精译与推文细节
【推文 1】代表你进行交易的个人 Agent 具有巨大的变现潜力。如果你设想 Agent 能够完美地端到端处理任意复杂的任务，那么最终大量的商业活动将不可避免地通过它们进行。你最初会把日常琐碎且烦人的任务交给 Agent，随着习惯养成，人们会开始让它们处理更复杂的任务，最终通过这些系统产生的支出将超过以往。如果你能降低商业和服务中的摩擦，人们的消费意愿反而会更高。这不仅为 Agent 提供商（如 Muse 等）创造了大量机会，也为构建 Agent 所需交互的底层（商业、本地服务、B2B 服务等）创造了全新机遇，实现了多层级的共赢。 【推文 2】AI Agent 使用软件的频率将是人类的 100 倍。即使随着交互界面逐渐隐形，Agent 仍需依赖人类过去使用的许多核心基础功能。事实上，当 Agent 能够在我们的系统中执行具有破坏性的操作，或者其访问的上下文决定工作流成败时，这些核心基础功能反而变得更加重要。无论是 CRM、ERP 还是结构化/非结构化数据平台，情况皆是如此。目前，能够作为 Agent 安全层和护栏、管理 Agent 与人类数据、并编排工作流业务逻辑的平台，正面临巨大的机遇。无论是初创公司还是转型迅速的现有平台，都拥有广阔空间。
