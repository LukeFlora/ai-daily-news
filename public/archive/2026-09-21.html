Box CEO Aaron Levie 深度剖析了 AI Agent 时代的范式转移：未来的竞争核心不再是争夺人类注意力，而是争夺 Agent 的“调用权”。随着 Agent 成为推理任务的主力，构建能够被 Agent 顺畅调用的工具生态（如 MCP、CLI 等）将成为继 App Store 之后最大的消费科技机遇。

个人智能体（Personal Agents）是“构建智能体所需之物”这一理念的终极体现。像 Muse 这类产品的形态，核心在于你能将任务全权委托给智能体，并确保其端到端地完成。为此，智能体必须能够顺畅地操作你的工具或使用其自身能力来完成任务——无论是通过 MCP 或 CLI、轻松导航网站，还是进行交易等。你需要竞争的新型注意力不再来自用户本身，而是来自智能体。这意味着，那些能让智能体高效订餐、处理电商交易、预订航班、融入本地经济并与我们的数据和信息交互的工具，将成为使用率最高的工具。这终将成为自 App Store 以来消费科技领域最大的机遇与洗牌。此外，Jev 在企业工作流的瞬间决策、数据分类和判断中极具价值。通过 Box 与 Jev 的集成演示，我们可以看到它能即时处理事故报告、自动分类并设置元数据，这种低成本、高效率的模式在保险理赔、合同管理及安全审查等领域潜力巨大。目前，智能体已占据推理任务的大多数，未来一两年内这一比例将趋于饱和。全球绝大多数 Token 将由在后台 24/7 运行的智能体消耗，它们将负责代码安全、数据处理、招聘研究及系统日志分析等海量任务。智能体上线速度未见放缓，仅过去一周，我就引入了多个一个月前技术上尚不可行的全新工作流。现在是深耕推理领域并在此基础上进行构建的绝佳时机。
