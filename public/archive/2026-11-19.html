Box CEO Aaron Levie 指出，AI Agent 正从简单的问答工具演变为具备自主规划、执行与持续优化能力的系统。这种从“任务执行”到“目标导向”的范式转移，将使 AI 能够完成人类以往无法企及的复杂工作，彻底重塑知识型工作的生产力边界。

无论如何定义，我们显然正在迈向工作流中 AI Agent 的又一个新时代。 我们已经迅速从只能给出快速回答的 Agent，进化到了如今可以在一系列任务中进行编排的 Agent。随着 Agent 能够实现多任务并行处理、处理更大规模的上下文、执行长周期任务，并具备更强大的能力，我们正进入 AI 赋能的新阶段。 很快，我们将能够为 Agent 设定目标，它们不仅能设计出实现目标的最佳方案，还能根据执行过程不断进行自我优化。这一变革将首先从工程领域开始，因为在几乎每一个 AI Agent 的新时代，最佳实践往往最先在工程领域涌现。 但其影响将波及整个知识工作领域。你可以要求 Agent 优化客户入职流程以实现特定目标；或者让 Agent 降低业务风险；亦或是持续提升企业的安全态势。 这些自主系统将能够接收目标、设计最佳方案、测试并迭代、部署，并持续优化其构建的成果。重要的是，这将带来人类此前无法实现的结果，从而将 AI 驱动的生产力提升到一个全新的高度。
